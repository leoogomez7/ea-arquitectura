## Application architecture
- Keep this explicitly requested one-page experience at `/` with in-page anchors, because the brief requires a continuous narrative.
- Keep conceptual project data separate from presentation; never turn missing studio facts into fabricated values.
- Contact submission must remain clearly unavailable until an actual delivery service is configured; file selection and validation do not imply delivery.
- Define the visual system centrally in `src/styles.css` and expose architectural Button variants to preserve consistent theming.
